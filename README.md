# LaserDino — инди-игра про динозавра с лазером

**LaserDino** — это инди-игра, в которой игрок управляет динозавром,
использующим лазер для борьбы с врагами и преодоления препятствий.

Официальный сайт игры:  
👉 https://onefreeusername.github.io/LaserDino_Landing/

---

## 🎮 Об игре LaserDino

LaserDino — это аркадная игра с динамичным геймплеем, простой механикой
и постепенным усложнением. Игроку предстоит управлять динозавром,
избегать опасностей и использовать лазер для уничтожения противников.

Игра создаётся как **indie-проект** и развивается постепенно.
